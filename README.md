# Project Title: New York Times Article Analysis
This project analyzes how public discourse, media framing, and cultural narratives of the topics New Year, Zoom Platform, and GPT Models change over time by evaluating a multi-year dataset of New York Times articles (data/nyt_articles.txt). Using a second dataset (data/) that measures each article's sentiment level, it analyzes the proportions of positive and negative sentiment articles for each topic to evaluate if the New York Times might be biased against certain topics.

# Python Libraries Used: 
NumPy, Pandas, Matplotlib, Seaborn, RegEx
