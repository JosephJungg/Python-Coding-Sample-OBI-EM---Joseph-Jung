# Project Title: New York Times Article Analysis
This project analyzes the frequency of the topics New Year, Zoom Platform, and GPT Models appearing in New York Times articles during each yearly quarter using the primary dataset (data/nyt_articles.txt). Using a second dataset (data/nyt_sentiments.csv) that measures each article's sentiment level, it analyzes the proportions of positive and negative sentiment articles for each topic to evaluate if the New York Times might be biased against certain topics.

# Python Libraries Used: 
NumPy, Pandas, Matplotlib, Seaborn, RegEx
