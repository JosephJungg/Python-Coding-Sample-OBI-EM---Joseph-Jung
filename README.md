# Project Title & Executive Summary: 
This project analyzes how public discourse, media framing, and cultural narratives evolve over time by evaluating a multi-year dataset of New York Times articles (JSON format). By combining temporal term frequency tracking with Natural Language Processing (NLP) sentiment analysis, this project measures both how often specific key terms appear over several years and how those terms are portrayed (primarily positive, negative, or neutral sentiment).

# The Tech Stack: 
NumPy, Pandas, Matplotlib, Seaborn, RegEx
